# Web Reference

This folder contains the previous TypeScript/React implementation for reference while rebuilding the app as a fully native iOS SwiftUI application.

It is not the active app target. Do not add Capacitor/PWA dependencies back to the native iOS project from here.

Use this folder to compare:
- layout and spacing
- poker timer behavior
- player actions and elimination logic
- prize pool settings
- game info dialogs
- reference/rules content
